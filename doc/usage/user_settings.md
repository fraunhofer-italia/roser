# User Settings

Roser allows the user to modify some behaviors by setting the following environment variables:

- **ROSER_ALWAYS_ON_TOP**: Default value ``true``. Defines if the spawned terminals are set as always on top.
  
- **TERMINAL_PROVIDER**: Default value ``""``. Allows to select another terminal provider.
  
- **BUILD_DEVCONTAINER**: Default value ``false``. Defines whether Roser installs Visual Studio Code extensions in the container each time the build command is executed on a Petal (nothing changes for Host Petals). Otherwise the extensions are installed only at the first launch of the Bud Command ``code`` given with the options ``--container``.
