# Other Installation Solutions

## User
  
To install a **specific stable** version (i.e. v1.0.0-beta):

```bash
pip install -U git+https://github.com/fraunhofer-italia/roser.git@v1.0.0-beta
```

Instead to install the **last unstable** version run the command:

```bash
pip install -U git+https://github.com/fraunhofer-italia/roser.git@devel
```

## Roser Developer
  
To install the developer version, clone the ``devel`` branch of the repository and then run the following command inside the folder:

```bash
pip install -e .
```
